About this page

A single HTML file tracking the 2026 FIFA World Cup: the all-time scoring record, the Golden Boot race, the Round of 32, the title odds, and the final group tables. No build step, no backend — the only external request is the Google Fonts stylesheet.

It's a snapshot, not a live feed. A standalone HTML file can't poll a data feed (no backend, and browsers block cross-origin calls). Every figure marked Live was current as of Jun 28, 2026 and will drift as matches are played. Group tables are final. A true live version would need a small backend proxy.

Verify before you lean on it

Live trackers disagree mid-match and lag real time. Cross-check active goal totals and odds against the official FIFA site before quoting them.
