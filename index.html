About this page

A single HTML file tracking the 2026 FIFA World Cup: the all-time scoring record, the Golden Boot race, the full knockout bracket, the final odds, and the group tables. No build step, no backend — the only external request is the Google Fonts stylesheet.

It's a snapshot, not a live feed. A standalone HTML file can't poll a data feed (no backend, and browsers block cross-origin calls). Every figure marked Live was current as of Jul 15, 2026 — after both semi-finals — and only the final and third-place match can still move them. Group tables and knockout results through the semis are final.
